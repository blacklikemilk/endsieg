# Era audit: Iran 1919-1925 (Anglo-Persian Agreement, 1921 coup, Reza Khan, Qajar survival)

Read-only audit. No script was modified.

Files examined:

- `common/national_focus/iran_interwar.txt` (2 032 lines, 132 focuses, tree `iran_interwar`)
- `common/scripted_effects/iran_campaign.txt` (`iran_settle_*`, `iran_refresh_mechanics`, `iran_initialize_campaign`)
- `common/scripted_effects/iran_coup_1921.txt` (`iran_coup_init` / `_tick` / `_clamp`)
- `common/decisions/iran_coup_1921.txt` (five coup decisions)
- `common/decisions/iran_great_powers.txt` (Anglo-Persian crisis mission + ratify/reject decisions)
- `common/script_constants/iran_campaign.txt`, `common/scripted_triggers/iran_continuity.txt`, `common/scripted_effects/iran_great_game_acts.txt`, `common/scripted_effects/PER_bop_effects.txt`
- `common/decisions/iran_campaign.txt`, `events/iran_campaign.txt`, `localisation/english/iran_interwar_l_english.yml`, `localisation/english/iran_campaign_l_english.yml`
- `docs/systems/iran_great_game.md`, `docs/systems/crown_and_majlis.md`, `docs/systems/iran_coup_1921.md`, `docs/plans/iran_1910_1945/*` (report, icon assignment)

Method: the focus file was parsed programmatically (id, x/y, icon, prerequisites, mutual exclusions, durations, rewards); the graph was walked for reachability; every flag a focus sets was searched across `common/` and `events/`; every icon was resolved against the 6 223 sprites in the installed game's `interface/goals*.gfx`. Nothing below is impressionistic — coordinates, connector spans, flag consumers and icon free/busy state were computed.

Scope: rows `y = 0-14, x = 0-51` (the 1919-1925 political spine, the six settlements, their continuations and `IR2_the_state_in_1935`). The economy (`x 54-68`), army (`x 74-80`), diplomacy/influence (`x 88-100`) and regional (`x 106-112`) branches are out of scope except where they are the only Great Game link a political route has.

## 1. Thin, repetitive or generic-reward focuses

### 1.1 The six capstones are the same focus six times

All six terminal writes are `set_country_flag` + stability + `iran_authority` + `iran_refresh_mechanics` + political power:

| Focus | Reward after the shared package |
| --- | --- |
| `IR2_restoration_capstone` | nothing else |
| `IR2_constitutional_capstone` | nothing else |
| `IR2_republic_capstone` | nothing else |
| `IR2_pahlavi_capstone` | nothing else |
| `IR2_nationalist_capstone` | nothing else |
| `IR2_socialist_capstone` | nothing else |

None of the six unlocks a decision, advisor, law, claim, unit, spirit or map change. A Qajar autocracy and a republic of councils end in the identical reward package, one row below six genuinely different settlement effects. That is the tree's largest reward-diversity defect, and it makes `IR2_the_state_in_1935` (which only reads the six `*_settled` flags) the sole late payoff.

### 1.2 Write-only flags

40 of the flags these 70 focuses set are read by **no** script file outside `iran_interwar.txt`:

`iran_anti_concession, iran_british_advisers, iran_civil_code, iran_civilian_control, iran_court_ministries, iran_economic_independence, iran_electoral_programme, iran_gilan_republic, iran_governors_of_the_crown, iran_gulf_claims, iran_household_brigade, iran_interwar_settled, iran_iranian_academy, iran_jangali_congress, iran_labour_law, iran_land_reform_debate, iran_land_to_the_peasants, iran_landlord_settlement, iran_majlis_restored, iran_military_academy, iran_national_militia, iran_national_union, iran_nationalist_movement, iran_nationalist_officers, iran_nationalist_press, iran_oil_revision, iran_pahlavi_army, iran_press_restraint, iran_provincial_governors, iran_red_gendarmes, iran_republican_constitution, iran_royal_authority, iran_royal_works, iran_secular_courts, iran_socialist_congress, iran_soviet_accord, iran_soviet_trade, iran_state_enterprises, iran_tribal_disarmament, iran_workers_councils`

Each of these focuses therefore *is* its stat package; the flag is decoration. (`iran_majlis_restored`, `iran_cabinet_responsibility`, `iran_electoral_law` are additionally absent from `iran_path_majlis` — see §4.1, which is why they cannot even be read indirectly.)

### 1.3 Pure filler in the socialist chain

`IR2_socialist_support` needs 50 (`iran_story.socialist_support_needed`). `IR2_gilan_republic`, `IR2_jangali_congress`, `IR2_soviet_accord` and `IR2_socialist_congress` each add exactly +15. The first three reach 45; `IR2_socialist_congress` (70 days) exists to add the fourth +15 and cross the threshold, and its other rewards are a flag nothing reads, PP and stability. Same pattern in the nationalist chain: `IR2_nationalist_press` and `IR2_nationalist_officers` exist only to set `iran_nationalist_officers`, which is read by exactly one `available` block (`IR2_nationalist_front`).

### 1.4 One reward shape repeated four times

`IR2_royal_works` (266), `IR2_state_enterprises` (266), `IR2_textile_industry` (410), `IR2_sugar_refinery` (416) are the identical `add_extra_state_shared_building_slots = project_slots` + `industrial_complex level 1 instant` bundle with only the state id changed. `IR2_landlord_settlement` (413) and `IR2_land_reform_debate` (417) are the identical one-level-infrastructure package with opposite narratives.

### 1.5 Other single-package focuses

`IR2_nationalist_press` (authority + stability + PP), `IR2_electoral_law` (PP + stability), `IR2_national_union` (PP + stability), `IR2_royal_authority` (authority + PP + stability), `IR2_household_brigade` (army XP + CP + WS), `IR2_civilian_control` (army XP + stability), `IR2_elections_1928` (PP + stability + `PER_bop_push_majlis_small`), `IR2_civil_service` (research slot + stability), `IR2_iranian_academy` (research slot + stability).

### 1.6 Dead ends

`IR2_majlis_restored`, `IR2_british_advisers`, `IR2_socialist_congress`, `IR2_nationalist_press`, `IR2_nationalist_officers` are terminal nodes with no child and no payoff beyond their stat package. `IR2_majlis_restored` is the worst: it is the *reward for rejecting the Anglo-Persian Agreement* (the chapter's central decision) and it grants `PER_bop_push_majlis`, stability, PP and authority, then stops. The Majlis never gets a follow-up.

## 2. Missing links to the Great Game and Crown/Majlis

Only 7 of the 70 in-scope focuses touch either mechanic directly, plus the six settlements (through `iran_settle_*` → `PER_bop_settle_*`):

| Branch | Crown/Majlis | Great Game |
| --- | --- | --- |
| pre-settlement trunk | `IR2_majlis_restored`, `IR2_cabinet_responsibility`, `IR2_the_coup_of_1921` | `IR2_reject_the_agreement`, `IR2_accept_the_agreement`, `IR2_british_advisers` |
| Qajar | `IR2_court_ministries`, `IR2_governors_of_the_crown` | `IR2_press_restraint` (concede_leading_small only) |
| Constitutional | `IR2_ministers_before_the_majlis`, `IR2_constitutional_army` | `IR2_budget_control` |
| Republic | `IR2_republican_constitution`, `IR2_elections_1928` | **none** |
| Pahlavi | none (balance removed — correct) | **none in the whole branch** |
| Nationalist | **none** | `IR2_economic_independence`, `IR2_oil_revision` |
| Socialist | **none** | `IR2_soviet_trade`, `IR2_anti_concession` |

Specific gaps that should be closed, with the exact effect:

1. `IR2_soviet_accord` — "Supplies from Moscow" gives equipment, opinion and +15 socialist support and costs the Great Game **nothing**, while its mirror `IR2_accept_the_agreement` charges `iran_concede_british_large`. Add `iran_concede_northern_small = yes` + `hidden_effect = { iran_refresh_mechanics = yes }`. Without it the left's patron is free and the right's is not.
2. `IR2_cossack_brigade` — the focus that makes the brigade "the strongest organized force in the country" moves no balance at all. Add `PER_bop_push_crown_small = yes`.
3. `IR2_reza_khan_minister` — the actual seizure of the army moves no balance (`IR2_the_coup_of_1921` pushes `PER_bop_push_crown_large`, the ministry that consolidates it pushes nothing). Add `PER_bop_push_crown_large = yes`.
4. `IR2_nationalist_officers` — the nationalist route has **zero** Crown/Majlis interaction until its settlement, so the "officers of the nation" cannot be seen moving the balance while they gather. Add `PER_bop_push_crown_small = yes`.
5. `IR2_royal_administration` / `IR2_pahlavi_capstone` — the historical route runs 1925-1935 with no Great Game lever; APOC 1933 sits in the economy branch (`IR2_oil_renegotiation`). Add `iran_reclaim_british_small = yes` + `iran_refresh_mechanics = yes` to `IR2_pahlavi_capstone` so the Pahlavi route can end with sovereignty rather than only stability.
6. `IR2_qajar_restoration` — the settlement that "resumes the government it lost" removes `iran_foreign_dependence` and pushes the crown, but restores no sovereignty. Add `iran_reclaim_leading_large = yes` (or `iran_reclaim_british_large = yes` specifically) so the Qajar ending has a Great Game price/prize.
7. `IR2_the_coup_of_1921` fires `iran_campaign.50`, whose option `iran_campaign.50.b` is "the coup was resisted" — but the focus has already applied `PER_bop_push_crown_large` and `iran_reza_influence +30`. The event should either set a resistance flag that costs influence (`subtract_from_variable iran_reza_influence = reza_purge_loss`) or be moved behind a decision.

## 3. Alternate-history gaps

3.1 **There is no no-coup path, structurally.** Graph walk over prerequisites: every route to `IR2_the_final_settlement` passes through `IR2_the_coup_of_1921` → `IR2_reza_khan_minister` → (`IR2_landlord_settlement` | `IR2_provincial_governors`) → `IR2_dynastic_question`. All four paths are variants of the same spine. A Qajar restoration, a constitutional monarchy, a republic and a socialist republic are therefore *all* built on having executed the February 1921 coup and appointed Reza Khan minister of war, and the player must then spend 75-150 PP decisions (`iran_purge_the_cossacks`, `iran_buy_the_brigade`, `iran_majlis_motion_reza`) to undo the focus he was forced to take. The five coup decisions are well built; the tree gives them nothing to feed into.

3.2 **Qajar survival has no pre-1921 divergence.** `IR2_qajar_restoration` is only reachable at the 1924 constituent assembly, i.e. after the coup. No focus lets Ahmad Shah dismiss a cabinet, keep a loyal Cossack commander, or dissolve a Majlis before 1921 — the only anti-Reza tools are decisions, and they are all post-coup.

3.3 **The republic is gated on a flag this chapter never sets.** `IR2_parliamentary_republic.available` requires `iran_path_majlis = yes`. The trigger is an OR over `iran_majlis_seated, iran_anjomans, iran_anjoman_elections, iran_budget_authority, iran_free_press, iran_constitution_secured, iran_defended_constitution, iran_constitutionalist`. Of these, the interwar chapter can only produce `iran_constitution_secured` — and only through option *b* of `iran_campaign.22`, the event fired by `IR2_command_and_cabinet` (25 % AI weight, forced to 0 under historical focus). `iran_constitutionalist` comes from `iran_settle_constitution`, i.e. after the fan has already been resolved. Consequences: for a fresh 1919 start, `IR2_parliamentary_republic` is invisible in practice, and none of the Majlis *focuses* (`IR2_majlis_restored`, `IR2_cabinet_responsibility`, `IR2_electoral_law`) can open it.

3.4 **No Pahlavi variant other than the coup.** `IR2_pahlavi_settlement` requires (`iran_cossack_ascendant` | `iran_reza_khan_minister`) **and** `iran_reza_influence ≥ 60`, which the coup (+30 from a 25 opening) and the ministry (+20) satisfy by themselves. There is no node for Reza Khan as a constitutional war minister under a sitting Majlis, and none for the actual 1924 republican attempt (which `iran_settle_republic` does not represent — it produces a democratic republic under Foroughi).

3.5 **Any start after 1925-12-14 silently removes five of the six routes.** `iran_initialize_campaign` sets `iran_pahlavi` for `date > 1925.12.14`; five settlement branches carry `allow_branch = { NOT = { has_country_flag = iran_pahlavi } }`. A player starting in 1926-1935 can therefore never play Qajar, constitutional, republican, nationalist or socialist Iran — the alt-history is restricted to pre-1926 starts, and nothing in the tree says so.

3.6 **The six-settlement fan is one-shot by design but one branch has no exit ramp.** `iran_campaign` auto-settles Pahlavi at `date > 1936.6.30` if `iran_regime_settled` is unset, and the only warning is `iran_campaign.31` at 1934.1.1. A player deliberately slow-rolling the constitutional or Qajar branch loses the choice to a timer, not to a decision.

3.7 **No visible identity change on the Qajar ending, and no cosmetic name anywhere.** `iran_settle_qajar_restoration` promotes `PER_ahmad_shah_qajar`, who is already the leader, and keeps `ruling_party = neutrality`, so a "restoration" changes no portrait, no flag and no name — only the `iran_qajar_state` spirit. The republic, nationalist and socialist settlements at least inherit vanilla's ideology flag swap (`PER_democratic` / `PER_fascism` / `PER_communism`), but none of the six sets a cosmetic tag, so "Imperial State of Iran", "Republic of Iran" and the Qajar court are indistinguishable in the country name until the 1936 tree.

## 4. Prerequisite, mutual-exclusion and pacing problems

4.1 `IR2_parliamentary_republic` — dependency on `iran_path_majlis` with no in-chapter setter (see 3.3). Fix in `iran_continuity.txt` (add `iran_majlis_restored`, `iran_cabinet_responsibility`, `iran_electoral_law`, `iran_constitutional_programme`) rather than in the focus.

4.2 The wrong fork is mutually exclusive. `IR2_cabinet_responsibility` (Majlis cabinet, `PER_bop_push_majlis`) is mutually exclusive with `IR2_cossack_brigade` (army XP, war support, no balance push) — but **not** with `IR2_the_coup_of_1921`, which pushes `PER_bop_push_crown_large` and `iran_reza_influence +30`. A player can hold "A Cabinet Answerable to the Majlis" and "The Coup of February 1921" simultaneously, which is the one combination the chapter is about. The 1921 fork should be `IR2_the_coup_of_1921` vs `IR2_cabinet_responsibility`.

4.3 `IR2_gilan_republic` — prerequisite `{ IR2_cabinet_responsibility IR2_cossack_brigade }` is an OR across two focuses that are themselves mutually exclusive, 44 columns apart. Functionally it means "whichever side of the (wrong) fork you took", and visually it draws a 44-column return connector (see §5).

4.4 `IR2_dynastic_question` — prerequisite OR of `IR2_landlord_settlement` (14, 5) and `IR2_provincial_governors` (44, 5): the second parent's connector spans 30 columns to reach a node placed directly under the first parent.

4.5 Duplicate `allow_branch` blocks (copy-paste, identical content, on both a line and a later line): `IR2_royal_authority` (lines 459 and 463), `IR2_ministers_before_the_majlis` (569, 573), `IR2_responsible_government` (680, 684), `IR2_royal_administration` (788, 792), `IR2_national_union` (903, 907), `IR2_workers_councils` (1010, 1014). Harmless today, but six focuses carrying a duplicated key is a parser smell and an editing hazard.

4.6 Incomplete mutual-exclusion lists on the branch guards. Every settlement's `allow_branch` lists four of the five rival flags: `IR2_qajar_restoration` omits `NOT iran_constitutional_monarchy`, and the other five omit `NOT iran_qajar_restoration`. Latent only (the mutual exclusion still blocks the second focus), but it means a Qajar settlement leaves `IR2_constitutional_crown` drawn.

4.7 Date-gate asymmetry and dead triggers. `IR2_dynastic_question` requires 1923-06-30 and `IR2_the_final_settlement` 1924-06-30, so all six settlements are effectively 1924-07+. `IR2_qajar_restoration` **additionally** carries `available = { date > 1924.6.30 OR ... }`, which is dead weight behind its parent's gate and produces a confusing tooltip. The other five carry no date, so a 1920 click-through is impossible only because of the parent.

4.8 Pacing: gated but not filled. From 1919 the player can complete the entire political spine in ~364 focus-days, then sits behind the 1923-06/1924-06 gates for four years with **no** 1921-1923 political content (the 1921-24 Majlis, the 1924 republic attempt and the APOC crisis of 1922-23 are absent). The only 1919-1923 material is the left column (`IR2_gilan_republic` 1920-05-31 → `IR2_jangali_congress` → `IR2_soviet_accord`) and the coup decisions.

4.9 `IR2_press_restraint` is a parent of the Qajar capstone. A 35-day press law whose rewards are stability + `iran_concede_leading_small` + PP is one of the two prerequisites of `IR2_restoration_capstone`; the branch's terminal node therefore requires its weakest node twice over (`IR2_household_brigade` or `IR2_royal_works` are the only others in that row).

4.10 `IR2_the_state_in_1935` requires a capstone and 1932-12-31, and has no bypass. A player who never completes a settlement (e.g. because `iran_campaign` auto-settled Pahlavi at 1936-06-30 in a 1919 start that never clicked a settlement) still needs `IR2_pahlavi_capstone`, which requires the branch's six focuses.

4.11 The Anglo-Persian Agreement can be resolved twice, and can be re-imposed after rejection. `IR2_reject_the_agreement`/`IR2_accept_the_agreement` neither read nor write `iran_crisis_anglo_persian_done`, and do not `remove_mission = iran_crisis_anglo_persian_begin`. The crisis decision pair (`iran_crisis_anglo_persian_ratify`/`_reject`, 75 PP) resolves the same question independently. Net effects: (a) a player can reject by focus and still have the 300-day mission time out and impose the treaty (`iran_agreement_anglo_persian_imposed`, +15 influence, −10 sovereignty); (b) a player can ratify by decision (+15 influence, −10 sovereignty) and then take `IR2_accept_the_agreement` for another `iran_concede_british_large` (+15 influence) — 30 influence from one agreement; (c) `IR2_reject_the_agreement` and the reject decision stack two separate sovereignty gains.

## 5. Layout (computed from x/y)

No `relative_position_id` is used anywhere; all 132 focuses are absolutely placed. Tree extent: **x 0-112, y 0-14** (113 columns × 15 rows). The political block alone occupies **x 0-48**. For scale, a vanilla major's whole tree is ~30-35 columns wide; the 1919-1925 political chapter is ~1.5 vanilla trees wide and the full Iran chapter is ~3.

No two focuses share a cell, so there are no overlapping boxes. The problems are pitch, alignment and connectors:

5.1 **Mixed column pitch in adjacent rows.** The settlement fan is on a 6-column pitch (`IR2_qajar_restoration` 10, `IR2_constitutional_crown` 16, `IR2_parliamentary_republic` 22, `IR2_pahlavi_settlement` 28, `IR2_nationalist_front` 34, `IR2_socialist_republic` 40); their children are on a 2-column pitch (8/12, 14/18, 20/24, 26/30, 32/36, 38/42); the trunk is on a 22-44 column pitch (2, 28, 46 at y = 3). At normal zoom the y = 8 row shows six icons with five empty columns between each and the y = 10 row shows twelve icons nearly touching.

5.2 **`IR2_the_state_in_1935` (8, 14) is the worst-placed node in the tree.** It has one OR prerequisite over the six capstones at x = 8, 14, 20, 26, 32, 38 (y = 13). Its correct column is the fan centre, x ≈ 23; at x = 8 it reads as a child of `IR2_restoration_capstone` and drags five connectors (6, 12, 18, 24 and 30 columns) across the capstone row.

5.3 **Connectors that cross another branch.**
- `IR2_cossack_brigade` (46, 3) → `IR2_gilan_republic` (2, 4): 44 columns, running across the top of `IR2_reza_khan_minister` (28, 4).
- `IR2_provincial_governors` (44, 5) → `IR2_dynastic_question` (14, 6): 30 columns, while the same node's other parent `IR2_landlord_settlement` (14, 5) is a 0-column drop. One parent is directly above, the other is 30 columns away.
- `IR2_accept_the_agreement` (48, 1) → `IR2_command_and_cabinet` (24, 2): 24 columns; the mutually exclusive pair at y = 1 is 36 columns apart (12 vs 48) for a two-option choice.

5.4 **Every branch bends left at the capstone.** Each of the six branches is 5 columns wide with its head at the centre (10, 16, 22, 28, 34, 40) and its two children at ±2, but every capstone sits at head − 2 (`IR2_restoration_capstone` 8, `IR2_constitutional_capstone` 14, `IR2_republic_capstone` 20, `IR2_pahlavi_capstone` 26, `IR2_nationalist_capstone` 32, `IR2_socialist_capstone` 38), aligned under the left-hand grandchild rather than the branch centre. Systematic, so it reads as intentional lean rather than error — but it is off-centre by one column in all six, and it is what makes `IR2_the_state_in_1935` land in the Qajar column.

5.5 **Empty rows.** y = 0 has five nodes (30, 66, 78, 94, 110) leaving x 31-65 as a 35-column hole; y = 14 has two nodes (8, 54) leaving 45 empty columns between them. `IR2_economic_capstone` (54, 14) and `IR2_the_state_in_1935` (8, 14) are the only nodes on the last row and are not visually related.

5.6 Settlement-fan alignment: the fan centre is 25 while `IR2_the_final_settlement` sits at 24 (off by one, harmless). The fan's parents are `IR2_the_final_settlement` for all six, so the y = 7 → y = 8 elbow bus runs 30 columns along the top of the row.
