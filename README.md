# Endsieg: Ultimate Victory

Existing Endsieg: Ultimate Victory HOI4 mod for game version 1.19.*, tagged Map, Technologies, Historical, Graphics, and National Focuses. The project inventory indexes about 26,484 files across common/, history/, events/, gfx/, localisation/, and map/. Sampled files cover national focus, decisions, scripted effects and triggers, AI strategy and equipment, ideologies, and characters, and include WWI-era factions, joining rules, and peace treaty pressure. Localisation has language headers for eight languages. Documentation is Markdown kept in docs/.
