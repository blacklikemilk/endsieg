# German interwar icon set

The `focus_source/` directory holds one original 256 × 256 RGBA master PNG per
German interwar focus. Each focus has its own subject and its own DDS texture;
the motif list is in `tools/german_focus_icon_motifs.tsv`. The shared `source/`
directory holds the 16 icons used by German interwar ideas and decisions.

The icons use small, restrained metal bezels and simplified painted emblems
that stay legible at Hearts of Iron IV focus size. Do not use the Brandenburg
Gate or a similar triumphal gateway in this set. `INT_GER_roaring_twenties`
uses an economic growth emblem with rising bars, an arrow, and a coin.
When paper appears, it should look like a readable document with orderly
markings or a seal. Do not add paper to unrelated factory or military icons.

Map and globe illustrations follow the coastline references in
`map_references/`. These are generated by
`tools/build_interwar_map_references.py` from the mod's `map/provinces.bmp` and
`map/definition.csv`. The Saarland outline comes from state 1019's province
11531. The icons omit uncertain internal borders instead of inventing them.

After changing a focus master, run:

```text
python tools/package_interwar_german_focus_icons.py --package
python tools/package_interwar_german_focus_icons.py --check
```

For a generated raster image with a neutral exterior, import it first using
`--import-generated INT_GER_focus_id path/to/image.png`. The packager preserves
the illustration and only cuts out its neutral exterior, resizes it, writes
the 96 × 96 DDS texture, and updates the focus sprite definition.

The shared idea and decision masters are packaged with
`python tools/package_interwar_german_icons.py`.
