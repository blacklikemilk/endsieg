# Irish interwar leader portraits

- `INT_Arthur_Griffith.dds`: [Arthur Griffith (1871-1922), cropped](https://commons.wikimedia.org/wiki/File:Arthur_Griffith_(1871-1922)_(cropped).jpg), Wikimedia Commons. Public-domain photograph; unknown author, published before 1931.
- `INT_Michael_Collins.dds`: [Young Michael Collins Portrait](https://commons.wikimedia.org/wiki/File:Young_Michael_Collins_Portrait.jpg), Wikimedia Commons. Public Domain Mark; author unknown.
- `INT_WT_Cosgrave.dds`: [WT Cosgrave, circa 1922 (headshot)](https://commons.wikimedia.org/wiki/File:WT_Cosgrave,_circa_1922_(headshot).jpg), Wikimedia Commons. Public-domain photograph from the National Library of Ireland catalogue; A. H. Poole Studio.

The JPEG sources were cropped to the 156x210 leader-portrait ratio and converted to uncompressed RGBA DDS using the repository's existing Pillow-based asset workflow.
