# Overview: Persian era trunk, Eras I and II (1910 to 1935), added to generic_focus_ww1 for Persia only.
# Persia has no bespoke WWI tree, and the shared WWI focuses check has_focus_tree = generic_focus_ww1, so the trunk is a set of shared focuses.
# The root carries allow_branch = { original_tag = PER }; every other focus inherits it through its prerequisites, so no other country sees the trunk.
# WWI - Generic.txt adds the root with shared_focus = PER_the_persian_question. The trunk sits at y -11 to -2; the generic shared focuses start at y 0.
# Documented in docs/persia_era_focus_tree.md.
